# Contest Calendar

Automatically collects upcoming programming contests from:

- AtCoder
- CodeChef
- LeetCode
- Codeforces

and adds them to Google Calendar.

## Installation

### 1. Clone the repository and Install requireed libs

git clone https://github.com/Saurabh7-7/Contest-Calender.git
cd Contest-Calender
